# Update an existing guide

Use this when `guides/<name>/PLAN.md` already exists.

1. **Ask what happened** in one round: questions the group asked, where people got stuck, what changed in the tools, what the author wants to add or remove.
2. **Map each item to a step.** A question or a failure becomes a line in that step's *If it fails*; a missing piece becomes a change to the step or a new step; a tool change means running the step again.
3. **Show the change list** in the chat (one line per change) and wait for the author's OK.
4. **Run again only the steps you touched**, with new screenshots where the screen changed.
5. **Build, review and publish to the same link** (see `publish.md`). Progress saved in readers' browsers is keyed on the guide's file name and the step ids: keep both, and give new steps new ids.
6. Add a dated entry to the «Final state» section of `PLAN.md`.
